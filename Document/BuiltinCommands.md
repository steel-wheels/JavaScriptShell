# Builtin commands
This documentation descrived about the built-in commands of `jsh`.

* [`mode`](#mode) : switch between the shell mode and script mode.

## Commands

### `mode`
Switch between the shell mode and script mode.
#### Syntax
<pre>
mode [shell|script]
</pre>
Switch to the `shell` mode or `script` mode.
If the no arguments are given, this command prints the current mode.
